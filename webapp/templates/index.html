Raw register access

Address = OV7670 register number (0x00–0xC9). Only the low byte of a write reaches the camera.

Gamma curve

Color matrix

Each output chroma row = a weighted sum of R,G,B (coefficient ÷256, sign from MTXS). Swatches apply the matrix to reference colors (BT.601 luma + the generated Cr/Cb) — approximate, exact at the default.

Frame capture

Save PNG
Grab a 640×480 frame from PSRAM channel 1.

The FPGA captures a fresh camera frame into PSRAM channel 1, then streams all 640×480 RGB565 pixels back over Modbus FC03 (~10 s at 1 Mbaud). The bus is busy for the whole download.

OSD text overlay

8×16 white font on a 60×17 character grid (480×272 LCD). Each line is one screen row; the editor is capped at 60 columns × 17 rows. Click a glyph to insert a special Latin-1 symbol or a box-drawing/block pseudographic at the cursor.

Text is composited over the live video on the LCD.
